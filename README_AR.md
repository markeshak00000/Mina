# MINA MAINTENANCE — نسخة Windows

## الملفات
- `index.html`: واجهة البرنامج الأصلية بعد إزالة شاشة التفعيل وتسجيل الدخول وحذف السجلات التجريبية.
- `main.cjs`: تشغيل نافذة Windows باستخدام Electron مع منع فتح روابط خارجية داخل التطبيق.
- `package.json`: إعدادات بناء مُثبّت Windows ونسخة محمولة.
- `build/icon.ico`: أيقونة البرنامج والمُثبّت.
- `.github/workflows/build-windows.yml`: بناء تلقائي على GitHub Actions.
- `original-input.html`: نسخة احتياطية من الملف الذي استلمته قبل التعديل؛ لا تدخل في ملف التثبيت.

## رفع المشروع إلى GitHub
1. أنشئ مستودعًا جديدًا أو افتح مستودعك الحالي.
2. ارفع **محتويات هذا المجلد** إلى جذر المستودع، بما فيها مجلد `.github`.
3. افتح تبويب **Actions** وتأكد أن سير العمل **Build Windows App** يعمل.
4. بعد نجاح البناء، افتح تشغيل الـ workflow ثم قسم **Artifacts** لتنزيل `MINA-MAINTENANCE-Windows`.
5. للحصول على ملفات تنزيل دائمة في **Releases**، أنشئ Tag باسم مثل `v1.0.0` وادفعه إلى GitHub؛ سيبني النظام الملفات وينشرها تلقائيًا في الإصدار.

## ملفات Windows التي سيُنتجها البناء
- ملف `MINA MAINTENANCE-Setup-1.0.0.exe`: برنامج التثبيت مع اختصار سطح المكتب وقائمة Start.
- ملف `MINA MAINTENANCE-Portable-1.0.0.exe`: نسخة محمولة لا تحتاج إلى مُثبّت.

## البناء محليًا على Windows
يلزم تثبيت Node.js 24، ثم من Terminal داخل المجلد:

```powershell
npm install
npm start
npm run dist:win
```

ستجد المخرجات في مجلد `dist`.

## البيانات والنسخ الاحتياطي
- يبدأ البرنامج دون سجلات أو عملاء أو قطع غيار وهمية.
- تُحفظ السجلات التي تضيفها محليًا في تخزين المتصفح الخاص بالتطبيق على الجهاز نفسه.
- من **الإعدادات → النسخ الاحتياطي** استخدم **تصدير JSON** للاحتفاظ بنسخة يمكن استعادتها، أو **تصدير CSV** لفتح قائمة البيانات في برامج الجداول.
- لاستعادة البيانات، اختر ملف JSON تم إنشاؤه بواسطة البرنامج. لا تحذف بيانات التطبيق أو مجلد المستخدم قبل تصدير نسخة احتياطية.
- النسخ السحابي إلى Google Drive لم يتم ربطه بخدمة فعلية في الكود الأصلي؛ لذلك لن يعرض التطبيق رسالة كاذبة بأن النسخ السحابي قد تم.

## ملاحظات مهمة
- ملفات التثبيت لا يتم إنشاؤها داخل هذه البيئة؛ GitHub Actions سيبنيها على Windows بعد رفع الملفات وتشغيل الـ workflow.
- تم الحفاظ على الواجهة والصفحات الرئيسية قدر الإمكان، مع تعديل عناصر البيانات التجريبية والوظائف التي كانت تكتفي بعرض رسالة نجاح من دون تنفيذ حقيقي.
